# Architecture Technique

## Stack
- Frontend : Next.js 14 (App Router)
- Langage : TypeScript
- UI : Tailwind CSS
- Backend / DB : Supabase
- Emails : Resend

## Découpage applicatif
- /public : inscription et information
- /admin : dashboard administratif
- /teacher : interface enseignants

## Sécurité
- Séparation stricte des routes par rôle
- Contrôle d’accès côté serveur
- Validation des données à chaque étape

## Principe clé
L’auto-évaluation suggère un niveau, mais la décision finale est humaine et collégiale.
